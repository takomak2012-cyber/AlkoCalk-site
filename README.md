# Сайт AlkoCalk

Сайт разработчика для приложения **AlkoCalk**. Публикуется GitHub Pages
из корня этого репозитория (файлы лежат прямо здесь, без `docs/`).

Адрес: `https://takomak2012-cyber.github.io/AlkoCalk-site/`

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная — описание AlkoCalk, восемь режимов, кнопки загрузки |
| `privacy.html` | Политика конфиденциальности (нужна RuStore и 4PDA) |
| `download/AlkoCalk_*.apk` | Прямая загрузка сборки |
| `favicon.svg` | Иконка |
| `app-ads.txt`, `ads.txt` | Копии для справки — робот ищет файл в корне домена |

## Важно про app-ads.txt

Рабочий файл лежит **не здесь**, а в корне домена —
`https://takomak2012-cyber.github.io/app-ads.txt`, в репозитории
`takomak2012-cyber.github.io`.

Это принципиально: стандарт IAB и Яндекс требуют, чтобы файл находился
в корне домена. Адрес сайта — подпапка `/AlkoCalk-site/`, поэтому копия
рядом со страницами роботом Яндекса не используется.

Ссылка на файл с сайта ведёт на корневой адрес, а не на подпапку.

## Обновление версии APK

В `index.html` версия упоминается в трёх местах, менять
их нужно **вместе**:

1. Ссылка загрузки в кнопке: `href="download/AlkoCalk_X.YZ.apk"`
2. Атрибут `download="AlkoCalk_X.YZ.apk"` у той же кнопки
3. Текст кнопки и строка `.dlnote` под ней

Новый APK кладётся в `download/` с тем же именем.

## Настройка Pages

В Settings → Pages:

- Source: **Deploy from a branch**
- Branch: **main**, папка: **/** (корень)

## Локальный запуск

```
python -m http.server 8000
```

В браузере откроется `http://localhost:8000/`.

## Публикация

```
git add -A
git commit -m "Обновление"
git push
```

GitHub Pages обновит сайт в течение минуты после пуша.
