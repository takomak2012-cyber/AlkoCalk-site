Общие сведения

Приложение AlkoCalk (пакет com.alkoka.app) — калькулятор разбавления спирта. Разработчик: Вячеслав Долар, контакт — takomak2012@yandex.ru.

Приложение не требует регистрации, не создаёт учётных записей и не передаёт разработчику никаких персональных данных.

Какие данные обрабатываются

Все расчёты выполняются на устройстве пользователя. Введённые значения — крепость, объёмы, названия напитков — сохраняются только в локальном хранилище приложения на самом устройстве и никуда не отправляются.

Удалив приложение, пользователь удаляет эти данные вместе с ним.

Реклама

Приложение содержит рекламный блок внизу экрана. Для его показа используется Yandex Mobile Ads SDK (версия 8.6.0) компании ООО «Яндекс».

Рекламный SDK может автоматически передавать рекламным сетям сведения, необходимые для показа и оценки рекламы:

  • идентификатор рекламы (AD ID / GAID);
  • тип устройства и версия операционной системы;
  • характеристики экрана и язык интерфейса;
  • сведения о сетевом подключении;
  • приблизительное местоположение на уровне города — только при наличии доступного источника.

Обработка этих данных выполняется рекламной сетью на её собственных условиях. Разработчик доступа к ним не получает.

Политика конфиденциальности ООО «Яндекс»: yandex.ru/legal/confidential.

Разрешения Android

РазрешениеЗачем нужно
INTERNETЗагрузка рекламных блоков. Расчёты без интернета работают полностью.
ACCESS_NETWORK_STATEОпределение типа сети рекламным SDK.
AD_IDПерсонализация и оценка эффективности рекламы.
POST_NOTIFICATIONSУведомление о готовности настойки — напоминание, которое пользователь создал сам.
RECEIVE_BOOT_COMPLETEDВосстановление созданных напоминаний после перезагрузки устройства.
VIBRATEТактильный отклик при нажатии кнопок.

Приложение не запрашивает доступ к камере, контактам, геолокации, файловой системе, микрофону и SMS. Не использует отладочный режим и отладочную подпись.

Дети

Приложение предназначено для пользователей старше 18 лет и не направлено на аудиторию младше этого возраста.
